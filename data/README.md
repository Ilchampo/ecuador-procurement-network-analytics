# Data directory

- `raw/2025/` contains the twelve original monthly SERCOP JSON packages. Their contents are preserved as published; only filenames were translated for consistency.
- `processed/` contains analysis-ready CSV files generated by notebook 02.
- `neo4j/` receives graph-import tables and derived network metrics generated by notebook 05. Generated CSV files in this folder are ignored by Git.

The processed datasets retain source field names where those names are part of the analytical schema. Missing values are not silently inferred: each recovery rule is documented in the cleaning notebook.
